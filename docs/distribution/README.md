## Posting checklist

For every post:
- Set the canonical link to the deepgrain.ai article (LinkedIn long-form supports this)
- Use UTM params: `?utm_source=<channel>&utm_medium=social&utm_campaign=intel-distribution`
- Reply in the comments with one thoughtful follow-up; engagement signals lift reach
- After posting, run the IndexNow ping (auto on next 10-min tick) so the canonical re-crawls
